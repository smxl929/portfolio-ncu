## 📚 16 周实验目录树

本仓库用于存放本学期所有实验课的作品、报告、笔记与源代码。

```
portfolio-ncu/
├── .gitignore              ← 仓库的"黑名单",指定哪些文件不被追踪
├── README.md               ← 你正在看的这份介绍（本文件）
├── week-01/  ~  week-16/   ← 16 周实验文件夹
└── (后续可能添加) docs/ resources/ archive/
```

### 📂 每周目录约定

每周边目录建议结构（可按当周实验调整）：

```
week-XX/
├── README.md     # 本周实验说明、心得、参考资料链接
├── docs/         # 实验报告（PDF / Word / Markdown）
├── src/          # 源代码（若适用）
├── assets/       # 图片、截图、原始数据
└── notes/        # 学习笔记、备忘
```

## 🛠️ 使用本仓库

### 1. 在另一台电脑克隆（同步到本地）

```bash
git clone https://github.com/smxl929/portfolio-ncu.git
```

### 2. 当周工作完成后，提交并推送

```bash
git add .
git commit -m "week-03: 完成 XXX 实验报告"
git push
```

### 3. 与远程保持同步

```bash
git pull
```

## 🔐 安全提示

本仓库是 **公开仓库（Public）**，请**不要**提交以下内容：

- 任何含个人隐私的文件（身份证、银行卡照片等）
- 学校账号密码、校园网登录信息
- 任何 API Key / Token / 私钥
- 未经授权的教材扫描件 / 受版权保护的资料

> 上述类别一律使用 `.gitignore` 中的 `secrets/` 或 `*.pem` 规则排除；若不小心提交了密钥，**请立即**联系 GitHub Support 协助清理历史。
